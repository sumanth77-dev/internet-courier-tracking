# SkyRoute Frontend

Client application for **SkyRoute** — Real-Time Courier Tracking and Delivery Management Platform.

- Built with React 19 + Vite
- Tailwind CSS v4
- Leaflet maps & OpenStreetMap integration
- Socket.IO client for live GPS vehicle tracking
- Brand palette: Deep Navy `#142B45`, Steel Blue `#245B78`, Teal `#18A6A0`, Soft Background `#F4F6F8`

### Scripts
- `npm run dev`: Launch Vite local development server
- `npm run build`: Production bundle compilation
- `npm run preview`: Preview production build
- `npm run lint`: ESLint code quality checks
